# 🚀 N. Borkataki - Modern Developer Portfolio

A stunning, highly interactive personal portfolio built to showcase web development and design skills. The project focuses on providing a premium user experience with smooth scrolling, micro-interactions, and beautiful typography.

## ✨ Key Features

- **Dynamic Animations**: Implemented using GSAP for scroll-triggered elements, fisheye text effects, and custom cursors.
- **Smooth Scrolling**: Integrated Lenis to provide a buttery-smooth, fluid scrolling experience across all devices.
- **Modern UI/UX**: Designed with a clean, premium aesthetic using Tailwind CSS.
- **Responsive Design**: Flawless experience on both desktop and mobile screens, with tailored navigation and interactions.
- **Interactive Components**: Features a bento grid for skills, an infinite scrolling marquee, a particle canvas background, and an integrated contact form.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: 
  - [GSAP (GreenSock)](https://gsap.com/)
  - [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://lenis.studiofreight.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Form Handling**: [EmailJS](https://www.emailjs.com/)

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:5173` to view the application.
